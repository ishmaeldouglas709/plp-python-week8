# Personal Toolkit

A menu-driven Python program with four everyday tools: a unit converter, an expense tracker, a password checker, and a flashcard quiz for Python keywords. Everything runs in the terminal and needs only Python 3 with no extra libraries.

## Files

- `toolkit.py` - the full program.
- `toolkit_plan.txt` - the plan written before the build: tools, menu text, and concepts used.
- `screenshots/` - screenshots of the menu, an invalid choice, and each tool running.

## How to run

Requires Python 3.8 or newer.

```
python3 toolkit.py
```

Type the number of a tool and press Enter. Choose 5 to quit.

## Tools

1. **Unit Converter** - type `length`, `weight`, `temperature`, or `back`. Enter the units and value to convert.
2. **Expense Tracker** - add expenses with a category, view them, see totals by category, or remove the last one. Expenses of 100 or more are flagged.
3. **Password Checker** - enter a password (it is not saved) to get a score out of 6, a rating, and suggestions.
4. **Flashcard Quiz** - answer eight shuffled questions about Python. Type `quit` to stop early. Missed cards can be retried at the end.
